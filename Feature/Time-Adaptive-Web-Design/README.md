# Time-Adaptive Web Design

This skill guides designers building websites that respond to time, weather, and place.

## Use

Load `SKILL.md` when planning or building an ambient website.
Ask for a setting, audience, primary action, and available environmental inputs.
The skill produces a visual direction, state map, interaction map, and fallback plan.

| Input | Design decision |
| --- | --- |
| Local time and location | Solar light and palette transitions |
| Weather | Optional scene detail with an offline fallback |
| User-controlled time | Accessible timeline for exploring states |
| No WebGL | Static scene with the same content and controls |

## Example

[KrackedLab](https://github.com/strdst7/kdlabcreative-aimirah) is the design reference.
Its scene blends solar palettes, weather-driven motion, and an editorial interface.
The skill extracts the workflow without copying its source or assets.

KrackedLab uses AGPL-3.0. Check its license before reusing code or assets.
The skill itself requires no services, installs, or credentials.
